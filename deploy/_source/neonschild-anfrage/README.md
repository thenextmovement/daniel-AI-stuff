Approved landing page from the local neon-schilder-remix design, imported 2026-10-13 after mobile performance optimization. This directory is the versioned production source. All existing landing pages and configurator files remain independent.

Build: `npm ci` in this directory, then `python3 build-live.py`. Assets are the relative `assets` symlink into the dedicated public release directory. Change the release directory/prefix for future changed image assets because public assets have immutable caching.

`build-preview.py` retains the original visual composition/minification. `build-live.py` emits `deploy/neonschild/anfrage.html` and dedicated assets with absolute URLs. It extracts the current `/api/c` submit, persisted-receipt, WebKit-recovery and conversion helpers from the maintained LP template; it does not change the shared API or existing forms. Consent tags come from the current generated `/neon-schilder/` page. `live-integration.js` maps the new fields to the existing intake names and preserves the same request UUID for a retry. The Express draft hands its text/file to the classic form for completion.

Neighbour: all existing live routes, consent contracts and photo/motion design. Effect: Cloudflare Pages release only; no Ops deployment or workflow/database mutation.
